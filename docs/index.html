Get started

OpenMoat documentation

OpenMoat checks every command, file access, web request and MCP call your coding agent makes, blocks the dangerous ones, and leaves everything else to your agent.

OpenMoat runs on your machine, next to Claude Code, Codex or Cursor. Before the agent runs a command, reads or writes a file, opens a web page or calls an MCP tool, OpenMoat checks it against one policy that you control. Normal work goes on as before; reading your keys, sending them out, destructive commands and switching OpenMoat off are blocked.

#What it is not

Note

OpenMoat is not an AI model and does not guess. Written rules decide, so the same call gets the same answer every time, in about 10 ms. Nothing leaves your machine unless you export it. It does not replace your agent's own prompt or sandbox; it fills the gaps between them. What it cannot see is listed in Limits.
