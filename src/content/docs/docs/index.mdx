OpenMoat runs on your machine, next to Claude Code, Codex, Cursor, OpenClaw, GitHub Copilot CLI, pi, Gemini CLI, OpenCode or Hermes Agent. Before the agent runs a command, reads or writes a file, opens a web page or calls an MCP tool, OpenMoat checks it against one policy that you control. Normal work goes on as before; reading your keys, sending them out, destructive commands and switching OpenMoat off are blocked.

## How it works

<img class="om-diagram light" src="/assets/how-it-works-light.svg" alt="An AI coding agent wants to run a tool call. Through the agent's own hook, OpenMoat checks it against one local policy before it runs: npm test is allowed, a call with no rule is left to the agent's own prompt, a git hook write asks you, and reading ~/.ssh/id_rsa is denied. Allowed code still runs inside the OS sandbox and the egress proxy, and every decision goes into a local hash-chained audit log." />
<img class="om-diagram dark" src="/assets/how-it-works-dark.svg" alt="" aria-hidden="true" />

The same policy is written into the agents' own OS sandboxes (Claude Code, Codex, Cursor), so code inside an allowed command cannot reach your keys either; `openmoat run` does this for any agent. More in [How it decides](/docs/how-it-decides/).

## Supported agents

| Agent | Protection | Details |
|---|---|---|
| Claude Code | hook + OS sandbox (hook only on native Windows) | [Claude Code](/docs/agents/#claude-code) |
| Codex | hook + OS sandbox | [Codex](/docs/agents/#codex) |
| Cursor | hook + OS sandbox on macOS and Linux (hook only on Windows) | [Cursor](/docs/agents/#cursor) |
| OpenClaw | hook only (a `before_tool_call` plugin) | [OpenClaw](/docs/agents/#openclaw) |
| GitHub Copilot CLI | hook only | [GitHub Copilot CLI](/docs/agents/#github-copilot-cli) |
| pi | hook only (an extension) | [pi](/docs/agents/#pi) |
| Gemini CLI | hook only | [Gemini CLI](/docs/agents/#gemini-cli) |
| OpenCode (1 and 2) | hook only (a plugin) | [OpenCode](/docs/agents/opencode/) |
| Hermes Agent | hook only | [Hermes Agent](/docs/agents/#hermes-agent) |

`openmoat init` finds the ones you have and asks before setting up each; `openmoat status` shows the level each one has right now. What each agent's hook sees, where you answer its questions and what it does not cover: [Supported agents](/docs/agents/).

## Quick start

<Steps>

1. **Install**

   <Tabs>
   <TabItem label="Homebrew">

   ```bash
   brew install crocodile-labs/tap/openmoat
   ```

   </TabItem>
   <TabItem label="Shell installer">

   ```bash
   curl --proto '=https' --tlsv1.2 -LsSf https://github.com/crocodile-labs/openmoat/releases/latest/download/openmoat-installer.sh | sh
   ```

   </TabItem>
   <TabItem label="PowerShell">

   ```powershell
   powershell -ExecutionPolicy Bypass -c "irm https://github.com/crocodile-labs/openmoat/releases/latest/download/openmoat-installer.ps1 | iex"
   ```

   </TabItem>
   <TabItem label="Cargo">

   ```bash
   cargo install openmoat --locked
   ```

   </TabItem>
   </Tabs>

2. **Set it up for your agents**

   ```bash
   openmoat init
   ```

   It writes the default policy to `~/.moat/policy.yaml`, lists the agents it finds and asks before it sets up each one. Then start your agent in a new session.

3. **See a verdict**

   ```bash
   openmoat policy check "cat ~/.ssh/id_rsa"
   ```

   ```text
   ⛔ deny
      rules : secrets-paths
      reason: secret material: read /Users/you/.ssh/id_rsa
      also  : shell "cat ~/.ssh/id_rsa"
   ```

</Steps>

Every step, and what to expect from each agent: [Quick start](/docs/quickstart/).

Already have projects? Every project you open with a protected agent is covered from the next session, with nothing to add per project. How your policy applies there, and how to give one project its own rules: [Use it in your projects](/docs/your-projects/).

## What it is not

<Aside type="note">

OpenMoat is not an AI model and does not guess. Written rules decide, so the same call gets the same answer every time, in about 10–20 ms. Nothing leaves your machine unless you export it. It does not replace your agent's own prompt or sandbox; it fills the gaps between them. What it cannot see is listed in [Limits](/docs/limits/).

</Aside>
