OpenMoat runs on your machine, next to Claude Code, Codex, Cursor, OpenClaw, GitHub Copilot CLI, pi or Gemini CLI. Before the agent runs a command, reads or writes a file, opens a web page or calls an MCP tool, OpenMoat checks it against one policy that you control. Normal work goes on as before; reading your keys, sending them out, destructive commands and switching OpenMoat off are blocked.

## How it works

```text
agent wants to run a tool call
  │
  ▼
the agent's hook ──► openmoat guard ──► policy lock check ──► policy
                                                                │
          ┌─────────────────┬──────────────────┬────────────────┤
          ▼                 ▼                  ▼                ▼
        allow             defer               ask              deny
     the call runs   the agent's own    you decide, with   blocked, with the
                     prompt decides     the reason shown   rule and the reason
          │                 │                  │                │
          └─────────────────┴────────┬─────────┴────────────────┘
                                     ▼
                       audit log (local, hash-chained)
```

The same policy is written into the agents' own OS sandboxes (Claude Code, Codex, Cursor), so code inside an allowed command cannot reach your keys either; `openmoat run` does this for any agent. More in [How it decides](/docs/how-it-decides/).

## Quick start

<Steps>

1. **Install**

   <Tabs>
   <TabItem label="Homebrew">

   ```bash
   brew install crocodile-labs/tap/openmoat
   ```

   </TabItem>
   <TabItem label="Shell installer">

   ```bash
   curl --proto '=https' --tlsv1.2 -LsSf https://github.com/crocodile-labs/openmoat/releases/latest/download/openmoat-installer.sh | sh
   ```

   </TabItem>
   <TabItem label="PowerShell">

   ```powershell
   powershell -ExecutionPolicy Bypass -c "irm https://github.com/crocodile-labs/openmoat/releases/latest/download/openmoat-installer.ps1 | iex"
   ```

   </TabItem>
   <TabItem label="Cargo">

   ```bash
   cargo install openmoat --locked
   ```

   </TabItem>
   </Tabs>

2. **Set it up for your agents**

   ```bash
   openmoat init
   ```

   It writes the default policy to `~/.moat/policy.yaml`, lists the agents it finds and asks before it sets up each one. Then start your agent in a new session.

3. **See a verdict**

   ```bash
   openmoat policy check "cat ~/.ssh/id_rsa"
   ```

   ```text
   ⛔ deny
      rules : secrets-paths
      reason: secret material: read /Users/you/.ssh/id_rsa
      also  : shell "cat ~/.ssh/id_rsa"
   ```

</Steps>

Every step, and what to expect from each agent: [Quick start](/docs/quickstart/).

Already have projects? Every project you open with a protected agent is covered from the next session, with nothing to add per project. How your policy applies there, and how to give one project its own rules: [Use it in your projects](/docs/your-projects/).

## What it is not

<Aside type="note">

OpenMoat is not an AI model and does not guess. Written rules decide, so the same call gets the same answer every time, in about 10–20 ms. Nothing leaves your machine unless you export it. It does not replace your agent's own prompt or sandbox; it fills the gaps between them. What it cannot see is listed in [Limits](/docs/limits/).

</Aside>
