## Common problems

### Every call is denied with `kernel-integrity`

A pinned file changed without you accepting it: run `openmoat`, which shows the change and asks. [Details](/docs/troubleshooting/hooks-and-lock/#every-call-is-denied-with-kernel-integrity).

### A hook still runs `moat`

Run `openmoat init` once. [Details](/docs/troubleshooting/hooks-and-lock/#a-hook-still-runs-moat).

### `openmoat policy install` refuses a pack

The signature does not verify against a key you trusted. [Details](/docs/troubleshooting/policies-and-network/#openmoat-policy-install-refuses-a-pack).

### A repository's allow rules stopped applying after `openmoat trust`

`require_signed_repo_policy: true` wants a signature. [Details](/docs/troubleshooting/policies-and-network/#a-repositorys-allow-rules-stopped-applying-after-openmoat-trust).

### Every call in one project is denied

The project's `.moat/policy.yaml` does not parse. [Details](/docs/troubleshooting/policies-and-network/#a-repository-policy-denies-every-call).

### `openmoat audit verify --against` fails

The log was cut short or rewritten after you anchored it. [Details](/docs/troubleshooting/policies-and-network/#openmoat-audit-verify---against-fails).

### An older OpenMoat cannot open the audit log

Upgrade every `openmoat` on the machine to the same release. [Details](/docs/troubleshooting/policies-and-network/#an-older-openmoat-cannot-open-the-audit-log).

### An MCP server's tools are denied with `mcp-server-changed`

Run `openmoat mcp accept <server>`. [Details](/docs/troubleshooting/policies-and-network/#an-mcp-servers-tools-are-denied-with-mcp-server-changed).

### A wrapped MCP server shows no tools after an upgrade

Run `openmoat mcp accept` once. [Details](/docs/troubleshooting/policies-and-network/#a-wrapped-mcp-server-shows-no-tools-after-an-upgrade).

### A connection to a port other than 443 or 80 is refused

Add a `host:port` rule next to the bare host. [Details](/docs/troubleshooting/policies-and-network/#a-connection-to-a-port-other-than-443-or-80-is-refused).

### A call is denied with `no decision within 30 s`

Ask the agent to try again. [Details](/docs/troubleshooting/hooks-and-lock/#a-call-is-denied-with-no-decision-within-30-s).

### An agent shows "hook only" or "not protected"

`openmoat status` names the cause. [Details](/docs/troubleshooting/hooks-and-lock/#an-agent-shows-hook-only-or-not-protected).

### `openmoat doctor` warns about a project's `.claude` settings

Check the file before you start an agent there. [Details](/docs/troubleshooting/hooks-and-lock/#openmoat-doctor-warns-about-a-projects-claude-settings).

### `openmoat run` refuses on macOS 12

It needs macOS 13 or later; the hooks still apply. [Details](/docs/troubleshooting/hooks-and-lock/#openmoat-run-refuses-on-macos-12).

### Nothing seems to happen

Start a new agent session and run `openmoat status`. [Details](/docs/troubleshooting/hooks-and-lock/#nothing-seems-to-happen).

### The `openmoat` binary is missing or broken

Reinstall it, then run `openmoat status`. [Details](/docs/troubleshooting/hooks-and-lock/#the-openmoat-binary-is-missing-or-broken).

## Reporting a bug

```bash
openmoat doctor --bundle report.json
```

It writes one local file to attach to the report: the version, the operating system, each agent's hook state, the doctor checks and the last 20 decisions with only time, agent, tool, verdict and rule. Commands, paths, arguments and URLs are left out, and nothing is sent.

## A command you need is blocked

See [Something was blocked](/docs/blocked/). If the default policy is wrong, please report a **False positive** on [GitHub](https://github.com/crocodile-labs/openmoat/issues/new/choose).

## Found a way past OpenMoat?

Please report it privately, as described in [SECURITY.md](https://github.com/crocodile-labs/openmoat/blob/main/SECURITY.md). Valid bypasses become tests before the fix is published.
