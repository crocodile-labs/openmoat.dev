Commands marked **terminal** must be run by a person in a terminal of their own ([Commands](/docs/commands/)).

## MCP

| Command | What it does | Example |
|---|---|---|
| `openmoat mcp accept [<server>]` | Review a changed or new MCP server, or tools `openmoat mcp proxy` holds, and accept them. **Terminal** | `openmoat mcp accept github` |
| `openmoat mcp wrap [<server>…] [--sandbox] [--dry-run]` | Run stdio MCP servers through `openmoat mcp proxy`, which pins each tool; `--sandbox` also starts them under `openmoat run`. **Terminal** | `openmoat mcp wrap --dry-run` |
| `openmoat mcp unwrap [<server>…]` | Point them back at their own command. **Terminal** | `openmoat mcp unwrap` |
| `openmoat mcp proxy --server <name> [--sandbox] [--write <path>]… -- <command>` | The wrapper `openmoat mcp wrap` writes into the agent's configuration: the agent starts it, you do not. It is also the gateway: it passes a call only when the policy does not deny it and the agent's hook decided exactly that call (`mcp-unattributed` otherwise) | |

See [MCP pinning and the MCP proxy](/docs/mcp-servers/) and [The MCP gateway](/docs/mcp-servers/gateway/).

## Secrets

| Command | What it does | Example |
|---|---|---|
| `openmoat secret add gh` | Keep the GitHub token from the agent: `GITHUB_TOKEN`, sent only to `api.github.com`; shows the diff and asks. **Terminal** | `openmoat secret add gh` |
| `openmoat secret add <id> --host <host> (--env <NAME> \| --file <path>) [--header <name>]` | Keep another token from the agent, for that host only. **Terminal** | `openmoat secret add stripe --host api.stripe.com --env STRIPE_API_KEY` |
| `openmoat secret add <id> … --tls-terminate [--allow 'METHOD /path']…` | Also put the value into HTTPS to the host inside `openmoat run`, which decrypts it with its own CA, and only into the requests the rules name; any other request to the host is refused. Offers to make the CA. **Terminal** | `openmoat secret add gh --tls-terminate --allow 'GET /repos/**'` |
| `openmoat proxy ca init` | Make the CA `openmoat run`'s proxy decrypts HTTPS with, for the hosts of `tls: terminate` secrets only; shows what it covers and asks, then pins it. Again to rotate it or cover a new host. **Terminal** | `openmoat proxy ca init` |
| `openmoat secret list [--format json]` | Each brokered secret's host, header and source, never the value | `openmoat secret list` |

See [Token broker](/docs/keep-tokens-safe/) and [Secrets over HTTPS, for some requests only](/docs/keep-tokens-safe/https-injection/).
