<Aside type="note" title="Two facts that apply on several pages">

`openmoat run` needs macOS 13 or later, or Linux. It refuses to start on macOS 12 and earlier and on Windows. On Linux it starts the Isolated tier by default where bubblewrap works.

Antigravity CLI's hook is run by a real `agy` on Linux and macOS each week; on Windows it is preview. What `agy` does when the hook times out is not documented, so OpenMoat assumes the call runs then ([Protection by agent and OS](/docs/agents/protection/)).

</Aside>
