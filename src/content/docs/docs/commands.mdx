Run these in your own terminal. The ones that change what agents may do need a terminal, and the default policy denies them to agents. They also refuse to run when Claude Code, Codex, the Cursor CLI, OpenClaw, GitHub Copilot CLI, pi, Gemini CLI, OpenCode, Hermes Agent, the Continue CLI or `openmoat run` started them, even through a terminal wrapper, and read your answer from the terminal itself (on Windows only the terminal is checked). On macOS they also refuse in a terminal inside the Cursor editor, whose agent runs in the same process tree: use a terminal of your own.

Commands marked **terminal** on the pages below are those. Run without a terminal, they stop with ``moat: `<command>` must be run by a person in a terminal, not from a hook or script``.

<Aside type="note" title="The moat name">

Releases up to 0.7.0 called the command `moat`. Every install still puts a `moat` beside `openmoat` that runs it, so hooks and scripts that call `moat` keep working for a few releases; then the `moat` name will be removed. `openmoat init` moves the hooks to the new name, and `openmoat doctor` says when a hook still uses the old one.

</Aside>

## Exit codes

| Code | Means |
|---|---|
| `0` | allow or success |
| `1` | the agent `openmoat run` started exited with an error |
| `2` | deny |
| `3` | an ask nobody answered (`openmoat policy check`) |
| `64` | a usage or configuration error |

`openmoat guard` never exits 64: it denies with 2 instead, so a broken hook blocks rather than lets a call through.

Every option: [USAGE.md](https://github.com/crocodile-labs/openmoat/blob/main/docs/USAGE.md#commands).
