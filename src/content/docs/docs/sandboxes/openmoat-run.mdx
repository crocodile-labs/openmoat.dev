<Aside type="note" title="Read this when">

Your agent has no OS sandbox from OpenMoat (OpenClaw, GitHub Copilot CLI, pi, Gemini CLI, OpenCode, Hermes Agent, Continue CLI), or you run one with auto-approve.

</Aside>

```bash
openmoat run --write ~/.claude --write ~/.claude.json -- claude
openmoat run --isolate --write ~/.claude --write ~/.claude.json -- claude   # Linux
```

The two `--write` paths are Claude Code's own state, which it must write to run. Start `openmoat run` in a project, never in your home directory. Inside it:

- **Network goes only through the run's proxy**, on a loopback port, with a credential made for the run; a request without it gets `407`. On Linux, where bubblewrap can run, the agent gets a network namespace of its own with only loopback.
- **The agent's hooks still decide each call.** They run inside the sandbox and send each call to the `openmoat run` process outside it, which decides and records it.
- **npm and uv install no version published in the last 7 days** (`npm_config_before`, `UV_EXCLUDE_NEWER`).
- **Brokered secrets' variables are removed** before the agent starts. A secret with `tls: terminate` is put into HTTPS here and nowhere else, only for the requests its `allow` rules name ([Secrets over HTTPS](/docs/keep-tokens-safe/https-injection/)); `openmoat run` refuses to start when no pinned CA covers such a secret's host.
- **Nothing types into your terminal:** `TIOCSTI` is denied.
- **Turn the agent's own sandbox off:** sandboxes do not nest. Claude Code's `sandbox.enabled` fails inside, and Codex needs `--sandbox danger-full-access`. Credentials must not come from the keychain: use an API key or `apiKeyHelper`.

Before the agent starts, `openmoat run` prints how many places the sandbox is stricter or wider than the policy; `--verbose` lists each one. It needs macOS 13 or later, or Linux; it refuses on Windows. More on auto-approve: [Auto-approve and CI](/docs/auto-approve-and-ci/#run-a-whole-agent-in-a-sandbox).

<Aside type="note" title="Cursor CLI under openmoat run">

It needs its install directory in `sandbox.read_roots` (`~/.local/share/cursor-agent`), an allow rule for `api2.cursor.sh`, and its key in `CURSOR_API_KEY`:

```bash
CURSOR_API_KEY=… openmoat run --write ~/.cursor -- agent --sandbox disabled
```

</Aside>
